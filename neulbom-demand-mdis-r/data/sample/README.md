# 샘플 데이터 안내

`src/all_res_2021.R`가 읽는 MDIS 지역별고용조사(하반기 C형) 2021 CSV의 구조를 흉내 낸 샘플입니다. 컬럼: C1 가구단위일련번호, C3 조사연월, C4 가구주관계코드(1 가구주·2 배우자), C6 만연령, C16 최근3개월 월평균급여, C17 배우자동거여부, C20 시도코드, C21 시도가중값, C26 막내자녀연령. 2015–2020 스크립트는 연도별로 컬럼 번호가 다르므로 각 스크립트 상단 주석을 참고하세요.

- 생성 방식: numpy seed 42 난수, 실제 분포와 무관한 합성 데이터
- 행 수: 150
- 원천 데이터는 비공개이며 이 레포에 포함되지 않습니다.
