# 취약지역 점수 모델 산식 (공주시, 2023)

`notebooks/01_pre_data_분석.ipynb`의 점수환산 셀을 기준으로 정리했습니다. 수치·가중치는 코드에 있는 값 그대로이며, 가중치의 정책적 근거(사업 평가기준)는 비공개 보고서에 있습니다.

## 1. 분석 단위와 입력
- 단위: 공주시 **리(里)** (리 경계 shp의 `gid` = `코드`)
- 입력 지표표 컬럼: `코드, 행정기관, 리` + 아래 10개 지표 + `밀집도_400m`(참고용)

## 2. 10개 정량지표 (4개 항목)
| 항목 | 지표 | 산출 |
|---|---|---|
| 취약계층 비율 | 기초생활수급자_비율, 차상위계층_비율 | 리 인구 대비 % |
| 취약계층 비율 | 장애인_비율, 65세이상고령자_비율 | 리 인구 대비 % |
| 생활위생 인프라 | 상수도보급률, 하수도보급률 | 공급 가구 / 전체 가구 % (높을수록 양호 → 역방향) |
| 주택 취약도 | 30년이상_노후주택비율, 슬레이트주택_비율, 빈집_비율 | 리 주택 수 대비 % |
| 밀집도 | 밀집도_200m (참고: 밀집도_400m) | 주택 중심점 200m 버퍼 안의 주택 수 / 리 전체 주택 수 % |

## 3. 표준화
모든 지표를 `sklearn.preprocessing.MinMaxScaler`로 0–1 범위로 변환하고 소수 둘째 자리에서 반올림합니다.

## 4. 항목 점수와 가중치
표준화 값으로 항목 점수를 만든 뒤 가중치를 곱합니다. 상수도·하수도는 보급률이 높을수록 양호하므로 `(1 − 값)`으로 뒤집습니다.

| 항목 점수 | 구성 | 가중치 |
|---|---|---|
| 취약계층비율_기초생활수급자/차상위 | mean(기초생활수급자_비율, 차상위계층_비율) | × 6 |
| 취약계층비율_고령자/장애인 | mean(장애인_비율, 65세이상고령자_비율) | × 4 |
| 생활위생인프라_상수도 | (1 − 상수도보급률) | × 4 |
| 생활위생인프라_하수도 | (1 − 하수도보급률) | × 4 |
| 주택취약도_노후주택 | 30년이상_노후주택비율 | × 5 |
| 주택취약도_슬레이트 | 슬레이트주택_비율 | × 5 |
| 주택취약도_공폐가 | 빈집_비율 | × 2 |
| 밀집도_200m기준 | 밀집도_200m | × 4 |

## 5. 총합점수와 우선순위
`총합점수 = 8개 항목 점수의 합` (최대 34점). 총합점수 내림차순으로 리를 정렬해 TOP5를 대상지 후보로 제시하고, 각 후보의 항목 점수를 시 평균과 비교해 "어느 항목 때문에 취약한가"를 분해합니다.
